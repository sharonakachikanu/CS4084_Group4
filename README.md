# CS4084_Group4

About App:
Pastry Picks is a user-friendly Android application designed using Android Studio to simplify and enhance your shopping experience, particularly for groceries and everyday items. It allows you to create, manage, and track multiple shopping lists with seamlessly, ensuring you never forget that crucial ingredient or household essential the next time your shooping.

Main Features:
1. Register User/Create User
2. Sign in/ Login
3. Sign out
4. Update User info
5. Create or add new list
6. Delete List
7. Edit List name
8. Add item in list
9. Edit item in List
10. Delete iem in list
11. Search: Users are able to search items in lists
12. Preview items in List in hompage without clicking

Additonal Features:
1. Progress bar
2. Multiple Shopping List View
3. Display User Profile
4. Mark item purchased
5. Display undo button after delete
6. Map

Additional Tips:
  Scrolling: On all pages, you can scroll by clicking and dragging the screen.

Debugging Build Errors:
If you encounter errors while building the project, try the following steps in order:
  1. Stop the Gradle daemon: ./gradlew --stop
  2. Clean and rebuild dependencies: ./gradlew :app:dependencies
  3. Re-run the build process in Android Studio.
